The game functions as such:

There is a shared hub world. Players can join this hub would together and share the same state. The hub world is an 11x11 scene. No enemies are there. Players can move freely, and can overlap. When rendering, we pick one of the players on a tile (always preferring the player that we're rendering the game of).

Then players can type a command to render the dungeon. For that, each player gets their own level. The levels are pregenerated ahead of time and have different challenges. These levels are smaller too.
